## 🚀 Featured Project: Valorant Discord Tracker Bot

A Discord bot that shows Valorant ranks and recent match history with slash commands, working in every server it joins.

| Command | What it does |
| --- | --- |
| `/rank name tag [region]` | Current and peak rank with RR |
| `/matches name tag [region]` | Recent matches: result, map, agent and K/D/A |
